# NIPC: N‑terminal Importance Profile Clustering

**NIPC** (N‑terminal Importance Profile Clustering) is a Python tool that clusters proteins—typically cytochrome P450s—based on the position and shape of their N‑terminal importance peaks. It reads per‑residue importance CSV files generated by either **DIVA** (unsupervised) or **PIVOT** (supervised) and performs:

- Classification of proteins as **N‑terminal‑driven** or **Weak‑N** using mode‑specific peak criteria.
- Hierarchical clustering of the N‑terminal‑driven subset according to profile shape and peak location.
- Export of cluster assignments, gene lists, summary plots, and data tables for all figures.

The tool was developed to analyse the P450 superfamily from *Sophora tonkinensis* (see accompanying manuscript), but it can be applied to any protein family for which per‑residue importance scores are available.

> **Reference:**  
> Zhu Q. et al.,**The N-Terminus of *Sophora tonkinensis* Cytochrome P450s Evolves Neutrally yet Encodes Rich Functional Information: A Protein Language Model Analysis** (2026).

## Features

- **Dual‑mode classification** – supports both DIVA (`--mode diva`) and PIVOT (`--mode pivot`) importance metrics, each with its own biologically motivated peak criterion.
- **Automatic file detection** – reads CSV files with either `*_full_importance.csv` (PIVOT/SVM) or `*_residue_importance.csv` (DIVA); auto‑detects the importance column (`importance`, `final_score_norm`, or `final_score`).
- **Intelligent N‑terminal window** – window length is calculated per protein as a proportion of its total length, bounded by user‑defined min/max values.
- **Robust profile resampling** – variable‑length profiles are smoothed, interpolated to 50 fixed points, and normalised to [0,1] without enforcing directional alignment (N→C direction is preserved).
- **Automatic or fixed clustering** – hierarchical clustering with average linkage and correlation distance; number of clusters can be auto‑determined (default, min 3) or fixed by the user.
- **Human‑readable cluster labels** – clusters are named Early‑N, Mid‑N, or Late‑N based on the median or mean peak position; a warning is issued if within‑cluster peak dispersion exceeds 0.30.
- **Comprehensive outputs** – assignments (CSV), gene lists per cluster, mean profile plots with SEM, heatmaps, peak distribution histograms, and population‑averaged profiles – all with accompanying data tables for reproducibility.

## Input Data Format

Place all per‑protein importance CSV files in a single directory. Each CSV **must** contain a column named `position` (1‑based residue numbering) and at least one of the following importance columns (auto‑detected in order):

- `importance` – used by PIVOT/SVM output (files named `*_full_importance.csv`).
- `final_score_norm` – used by DIVA output (files named `*_residue_importance.csv`).
- `final_score` – fallback if neither of the above is present.

The script strips the suffixes `_full_importance` and `_residue_importance` to obtain the gene name. If the same gene appears in both formats, the first file encountered is kept; duplicates are reported and skipped.

## Usage

### DIVA mode (unsupervised topology template)

```bash
python NIPC.py \
    --importance-dir ./diva_results \
    --output-dir ./diva_clusters \
    --mode diva \
    --peak-ratio 0.85 \
    --weak-threshold 1.0
```

### PIVOT mode (supervised identity signal)

```bash
python NIPC.py \
    --importance-dir ./pivot_results \
    --output-dir ./pivot_clusters \
    --mode pivot \
    --peak-factor 1.5 \
    --weak-threshold 1.0
```

### Full parameter list

| Argument             | Type             | Default            | Description                                                  |
| -------------------- | ---------------- | ------------------ | ------------------------------------------------------------ |
| `--importance-dir`   | str              | **required**       | Directory containing the CSV files.                          |
| `--output-dir`       | str              | `./nterm_clusters` | Output folder (created if it does not exist).                |
| `--nterm-proportion` | float            | `0.15`             | Fraction of protein length used to define the N‑terminal window. |
| `--nterm-min`        | int              | `30`               | Minimum N‑terminal window length (residues).                 |
| `--nterm-max`        | int              | `100`              | Maximum N‑terminal window length (residues).                 |
| `--weak-threshold`   | float            | `1.0`              | Ratio `mean(N‑term) / mean(whole)` below which a protein is classified as Weak‑N. |
| `--mode`             | {`diva`,`pivot`} | `diva`             | Peak criterion mode. See below for details.                  |
| `--peak-ratio`       | float            | `0.85`             | **[DIVA mode]** N‑term max must be ≥ `peak_ratio` × global max. |
| `--peak-factor`      | float            | `1.5`              | **[PIVOT mode]** N‑term max must be ≥ `peak_factor` × N‑term mean. |
| `--n-clusters`       | int              | `None`             | Fixed number of clusters for the N‑terminal‑driven group. If `None`, auto‑selected (minimum 3). |

**Mode‑dependent classification logic:**

A protein is considered **N‑terminal‑driven** if **both** of the following conditions hold:

1. **Concentration criterion** (same for both modes):  
   `mean(N‑term) / mean(whole) ≥ weak_threshold`

2. **Peak criterion** (mode‑specific):  
   - **DIVA**: `max(N‑term) ≥ peak_ratio × max(whole)`  
     (tests whether the N‑terminus captures a large fraction of the global maximum – suited for smooth, min‑max normalised DIVA profiles).  
   - **PIVOT**: `max(N‑term) ≥ peak_factor × mean(N‑term)`  
     (tests whether the N‑terminal peak rises sharply above its local baseline – suited for sparse, high‑importance PIVOT profiles).

Proteins failing either criterion are assigned to the **Weak‑N** group.

## Output Files

All outputs are written to `--output-dir`. The following files are generated:

| File                               | Description                                                  |
| ---------------------------------- | ------------------------------------------------------------ |
| `nterm_profile_assignments.csv`    | Per‑gene assignment (cluster name or "Weak‑N") and the N‑terminal window length used for that protein. |
| `nterm_profile_genes.csv`          | Per‑cluster gene lists with counts (one row per cluster).    |
| `nterm_cluster_profiles.png`       | Line plot of mean ± SEM importance profile for each cluster (resampled to 50 positions). |
| `nterm_cluster_profiles_data.csv`  | Underlying data for the profile plot (cluster, position, mean, SEM, N). |
| `nterm_profile_heatmap.png`        | Heatmap of all resampled profiles, sorted by cluster; cluster labels are shown on a dedicated right‑hand strip. |
| `nterm_profile_heatmap_data.csv`   | Resampled profile matrix with gene names and cluster labels. |
| `nterm_peak_distribution.png`      | Histogram of relative peak positions (0–1) per cluster.      |
| `nterm_peak_distribution_data.csv` | Per‑gene peak positions and cluster assignment.              |
| `population_mean_profile.png`      | Population‑averaged importance over the first 50% of sequence length, with separate traces for N‑terminal‑driven vs. Weak‑N proteins. |
| `population_mean_profile.csv`      | Data table for the population profile (position, mean importance per group, counts). |

## Interpretation of Results

The console output summarises the classification and clustering statistics. Key points:

- **N‑terminal‑driven** proteins are those with a clear importance peak in the N‑terminal window according to the chosen mode.
- **Weak‑N** proteins lack such a peak; they may still carry important signals elsewhere in the protein.
- Clusters are labelled according to peak position within the window. If within‑cluster peak standard deviation exceeds 0.30, a warning is issued and the median peak is used for labelling (to avoid bias from outliers).
- In practice, **DIVA** typically yields a dominant **Early‑N** cluster (peak near positions 1‑13), reflecting a conserved membrane‑topology template.
- **PIVOT** often shows more diverse cluster distributions, with peaks shifted downstream (Mid‑N or Late‑N), capturing family‑identity signals.

The population‑averaged profile allows comparison of the overall importance distribution between N‑terminal‑driven and Weak‑N proteins.
